# Global Awards 2026

## Project overview

A modern awards and editorial-content website built with Next.js and Sanity CMS. The repository provides the web application, content-management configuration, motion/UI components, and public assets for an awards-focused digital experience.

## What it contains

- Next.js 16 and React 19 application
- TypeScript
- Sanity CMS configuration and image tooling
- Framer Motion animations
- Responsive UI components and public assets
- Standard development, lint, build, and start commands

## Technology

- **Frontend:** Next.js, React, TypeScript
- **Content:** Sanity CMS
- **UI:** Framer Motion and Lucide icons
- **Deployment fit:** Next.js-compatible hosting

## Current status

Application source and CMS configuration are present. The previous README was the default framework template, so the exact award program, public routes, content models, editorial workflow, and production deployment still need to be confirmed from the product owner and current application behavior.

## Local development

```bash
npm install
npm run dev
```

Run `npm run lint` and `npm run build` before publishing.
